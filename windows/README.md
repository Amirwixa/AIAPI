# AI Agent Hub - نگارش ویندوز (Windows Desktop)

نسخه بومی دسکتاپ اپلیکیشن **AI Agent Hub** توسعه‌یافته با **Python** و **PyQt5** با پشتیبانی کامل از زبان فارسی و راست‌به‌چپ (RTL)، تم تیره مدرن، بینایی ماشین (Vision) و اتصال به هوش مصنوعی‌های مختلف.

---

## ویژگی‌های نسخه ویندوز

1. **چند ایجنتی همزمان (Multi-Agent):**
   - ساخت نامحدود دستیار با نقش‌ها و مدل‌های مختلف (OpenAI, Gemini, OpenRouter, DeepSeek, Groq, Ollama).
   - ویرایش و حذف ایجنت‌ها با یک کلیک.
2. **پشتیبانی از پردازش تصویر (Vision / Multimodal):**
   - قابلیت انتخاب مستقیم تصاویر از روی هارد سیستم (`.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`).
   - فشرده‌سازی خودکار و ارسال همزمان با پیام به مدل‌های چندوجهی.
3. **ذخیره‌سازی کاملاً آفلاین و ایزوله:**
   - ذخیره تاریخچه‌ها و مشخصات در پوشه `data/` در کنار برنامه.
4. **رابط کاربری تیره و بهینه:**
   - چیدمان راست‌به‌چپ (RTL) مخصوص زبان فارسی.
   - قابلیت کپی کردن هر پیام با دکمه اختصاصی یا دابل کلیک.
   - نوار وضعیت و پروگرس‌بار لودینگ هنگام دریافت پاسخ مدل.

## نحوه اجرا

### روش اول: اجرای تک‌کلیک (پیشنهادی)
کافی است روی فایل زیر در ویندوز دابل کلیک کنید:
`run.bat`

### روش دوم: از طریق ترمینال (CMD یا PowerShell)
```powershell
cd C:\Users\ESMIT\.gemini\antigravity\scratch\ai-agent-hub\windows
python app.py
```

### روش سوم: ساخت فایل اجرایی مستقل (.exe)
برای تبدیل کل برنامه به یک فایل `.exe` مستقل بدون نیاز به پایتون:
```powershell
pyinstaller --noconfirm --onedir --windowed --name "AI-Agent-Hub" --add-data "data;data" app.py
```
فایل نهایی در مسیر `dist/AI-Agent-Hub/AI-Agent-Hub.exe` قرار خواهد گرفت.
